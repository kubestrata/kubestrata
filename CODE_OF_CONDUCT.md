# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, keep discussions about the work, and do not harass
anyone in issues, pull requests or any other project space. Maintainers may edit or remove
contributions and block participants who break these rules.

Report unacceptable behavior privately to the maintainer through the contact on the
[GitHub profile of @leosavio](https://github.com/leosavio). Reports are handled confidentially.
